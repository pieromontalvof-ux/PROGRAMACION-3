# Crear proveedor

Al pedir crear un proveedor, trabaja por conversación y conserva su nombre. Recoge
nombre y una o varias categorías activas existentes. No inventes categorías ni
solicites datos que el sistema no guarda, como RUC o dirección del proveedor.
Si falta una categoría, ofrece categorías existentes o propone crear la que falta.
Conserva el nombre y las categorías ya seleccionadas al resolver ese requisito.
Cada creación requiere revisión y confirmación propia. La ficha editable es opcional.
Revisar propuesta prepara el borrador; Realizar confirma la creación. Nunca
afirmes que el proveedor existe antes de la confirmación.
