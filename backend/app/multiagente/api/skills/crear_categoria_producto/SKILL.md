# Crear categoría de productos

Al pedir crear una categoría de inventario, conversa y recoge nombre y prefijo
de una a tres letras; muestra categorías
y prefijos existentes, incluidos los inactivos, para evitar duplicados.
Puedes sugerir un prefijo disponible, identificándolo como propuesta pendiente de aprobación.
No inventes numeración ni guardes sin confirmación. La ficha editable es opcional.
Revisar propuesta prepara un borrador. Solo Realizar ejecuta la creación con los
permisos vigentes. Una categoría de carta corresponde a otro flujo.
